# Guía de Aprendizaje - Sprint 1

## Proyecto: EMPLEATE

### 1. Objetivo del Sprint

En este Sprint se busca establecer las bases del proyecto EMPLEATE, configurar el entorno de desarrollo y comprender la estructura inicial de la aplicación.

El objetivo principal es que el equipo pueda trabajar de manera organizada utilizando Git y GitHub, además de identificar los requerimientos y funcionalidades que se desarrollarán durante el proyecto.

---

## 2. Objetivos de aprendizaje

Al finalizar el Sprint 1, el equipo deberá ser capaz de:

- Comprender la estructura de un proyecto Django.
- Crear y configurar un entorno virtual.
- Ejecutar un proyecto Django localmente.
- Comprender el funcionamiento de `models.py`, `views.py` y `urls.py`.
- Identificar las entidades principales del sistema.
- Comprender las relaciones entre tablas de una base de datos.
- Utilizar Git para controlar versiones.
- Utilizar GitHub para almacenar y compartir el proyecto.
- Crear ramas para trabajar en funcionalidades específicas.
- Realizar commits siguiendo una descripción clara.
- Crear Pull Requests para integrar cambios.

---

## 3. Herramientas utilizadas

Durante el desarrollo del proyecto se utilizarán las siguientes herramientas:

- Python
- Django
- SQLite
- Git
- GitHub
- Visual Studio Code
- PowerShell o Git Bash
