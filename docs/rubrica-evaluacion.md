# Rúbrica de Evaluación

## Proyecto: EMPLEATE

Esta rúbrica permite evaluar el desarrollo del proyecto EMPLEATE teniendo en cuenta aspectos técnicos, funcionales, de trabajo colaborativo y documentación.

---

## 1. Desarrollo de la funcionalidad — 25%

| Criterio       | Excelente                                                     | Bueno                                                     | Básico                                                   | Insuficiente                                    |
| -------------- | ------------------------------------------------------------- | --------------------------------------------------------- | -------------------------------------------------------- | ----------------------------------------------- |
| Implementación | La funcionalidad cumple completamente con los requerimientos. | La funcionalidad cumple la mayoría de los requerimientos. | La funcionalidad cumple parcialmente los requerimientos. | La funcionalidad no cumple los requerimientos.  |
| Código         | Código organizado, claro y correctamente estructurado.        | Código organizado con algunos aspectos por mejorar.       | Código con problemas de organización.                    | Código desorganizado o con errores importantes. |

**Puntaje:** ____ / 25

## 2. Base de datos y relaciones — 25%

| Criterio         | Excelente                                                                | Bueno                                                           | Básico                                | Insuficiente                                      |
| ---------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------- | ------------------------------------- | ------------------------------------------------- |
| Modelos          | Los modelos representan correctamente las entidades del sistema.         | Los modelos representan la mayoría de las entidades necesarias. | Existen modelos incompletos.          | Los modelos presentan errores importantes.        |
| Relaciones       | Las relaciones entre tablas están correctamente definidas.               | La mayoría de las relaciones están correctamente definidas.     | Algunas relaciones presentan errores. | No se implementaron correctamente las relaciones. |
| Tabla intermedia | La tabla intermedia está correctamente implementada cuando es necesaria. | La tabla funciona con pequeños aspectos por mejorar.            | La implementación es parcial.         | No se implementó correctamente.                   |

**Puntaje:** ____ / 25

## 3. Funcionamiento del sistema — 20%

| Criterio                | Excelente                                                  | Bueno                                               | Básico                                        | Insuficiente                                      |
| ----------------------- | ---------------------------------------------------------- | --------------------------------------------------- | --------------------------------------------- | ------------------------------------------------- |
| Ejecución               | El proyecto se ejecuta correctamente sin errores críticos. | Se ejecuta con errores menores.                     | Presenta varios errores durante la ejecución. | No es posible ejecutar correctamente el proyecto. |
| Registro de información | Los datos se registran y almacenan correctamente.          | La mayoría de los datos se almacenan correctamente. | Algunos datos presentan problemas.            | Los datos no se almacenan correctamente.          |
| Validaciones            | Las validaciones funcionan correctamente.                  | Existen algunas validaciones.                       | Las validaciones son insuficientes.           | No existen validaciones.                          |

**Puntaje:** ____ / 20

## 4. Git y GitHub — 15%

| Criterio              | Excelente                                        | Bueno                                                       | Básico                                       | Insuficiente                                |
| --------------------- | ------------------------------------------------ | ----------------------------------------------------------- | -------------------------------------------- | ------------------------------------------- |
| Repositorio           | El repositorio está organizado correctamente.    | El repositorio presenta pequeños problemas de organización. | El repositorio está parcialmente organizado. | El repositorio no está organizado.          |
| Commits               | Los commits son claros y descriptivos.           | La mayoría de los commits son claros.                       | Los commits tienen poca descripción.         | No existe un control adecuado de versiones. |
| Ramas y Pull Requests | Se utilizan correctamente ramas y Pull Requests. | Se utilizan con algunos errores.                            | Se utilizan parcialmente.                    | No se utilizan correctamente.               |

**Puntaje:** ____ / 15

## 5. Documentación — 10%

| Criterio          | Excelente                                            | Bueno                                               | Básico                              | Insuficiente                            |
| ----------------- | ---------------------------------------------------- | --------------------------------------------------- | ----------------------------------- | --------------------------------------- |
